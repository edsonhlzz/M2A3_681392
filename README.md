# M2A3_681392 - Actividad HTML Semántico + Validación W3C

Convertí una página basada solo en `<div>` a HTML semántico, reemplazando los divs de layout por `<header>`, `<nav>`, `<main>`, `<article>`, `<aside>` y `<footer>`. Usé `<h1>`/`<h2>` en vez de `<strong>` para títulos, `<time datetime="...">` para la fecha, `<blockquote>` con `` para la cita, y `<address>` para los datos de contacto.

Validado con el W3C Nu Html Checker: sin errores ni advertencias (ver `validacion_w3c.png`).
